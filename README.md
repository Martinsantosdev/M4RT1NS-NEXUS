🚀 Sobre o projeto 

O M4RT1NS.exe NEXUS 8.0 é um projeto desenvolvido em Python para consultar informações do dispositivo e facilitar tarefas de diagnóstico local no Android usando o Termux.

🧩 Funcionalidades Módulo Descrição 📱 Device Info Informações do dispositivo 📊 Performance Radar Indicadores de memória e desempenho 🔎 Large File Detector Identificação de arquivos grandes 📂 Smart File Organizer Visualização e classificação de arquivos 🗃️ Report Vault Salvamento e comparação de relatórios 🌐 Network Scanner Consulta de informações de rede disponíveis ⚙️ Requisitos Android Termux Python 3 Permissões necessárias para acessar determinados arquivos 

O projeto foi pensado para utilizar a biblioteca padrão do Python, sem bibliotecas Python externas.

▶️ Como executar 

Abra o Termux e digite:

cd ~/mobile-dashboard python dashboard.py 

Se necessário, utilize:

python3 dashboard.py 🔐 Segurança e privacidade Ferramenta destinada ao diagnóstico local. O detector de arquivos grandes identifica arquivos, sem apagá-los. Confira os caminhos antes de modificar arquivos. Utilize o scanner de rede somente em redes que você tem autorização para analisar. Os resultados dependem das permissões e limitações do Android. 🧑‍💻 Criado por
